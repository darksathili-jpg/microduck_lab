# La traversée — Première NSI

Objectifs : prévoir les effets d’un programme, utiliser variables et boucles, interpréter un booléen, construire une condition d’arrêt, tester et corriger. Référence : https://eduscol.education.gouv.fr/5823/programmes-et-ressources-en-numerique-et-sciences-informatiques-voie-g

1. **Observer** : départ, orientation, cible, obstacles et bords.
2. **Prévoir** : écrire une hypothèse dans le champ libre, sans prétendre l’évaluer automatiquement.
3. **Programmer** : créer une première boucle sur la ligne courte ; langage Python ordinaire.
4. **Tester** : comparer avec la ligne longue, puis utiliser le capteur sur quatre configurations déterministes.
5. **Comprendre** : distinguer erreur de syntaxe, exception, comportement incorrect et limites ; expliquer la condition d’arrêt.
6. **Transférer** : longueur différente, absence d’obstacle intérieur, robot déjà arrivé. Le même programme doit réussir toute l’étape capteurs.

Trois indices sont révélés progressivement dans chaque étape. La première étape permet de constater qu’un nombre fixe de pas ne généralise pas ; la seconde vise une solution guidée par l’état du monde. Les tests automatiques valident uniquement le comportement : l’enseignant valide raisonnement, prévision et explication.

À valider humainement : vocabulaire, difficulté, rythme d’introduction de `while`, moment de révélation des indices, lisibilité au vidéoprojecteur et adaptation aux élèves. Aucun BFS, Q-learning ou pilotage physique n’est développé.
